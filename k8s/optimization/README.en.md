# Kubernetes Optimization Recommendations

[한국어](README.md) · [English](README.en.md)

## Purpose

Configuration for collecting CPU/memory recommendations from KRR, Goldilocks, and VPA.

## Benefits

- Review usage and recommendations without automatically changing workloads.

## Features and structure

- The guide below defines configuration, prerequisites, commands, and operating contracts.

## Getting started

Read the [detailed configuration guide](GUIDE.en.md), verify the environment and inputs, and use the working directory indicated in the guide.

## Scope and limitations

Configuration examples do not establish real-environment validation. Review targets, permissions, and costs before running change commands. Product licenses or external API access may be required.
